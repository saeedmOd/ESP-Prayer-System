# 🕌 نظام الصلاة ESP

نظام إسلامي ذكي لمواقيت الصلاة مبني على ESP باستخدام ESP8266/ESP32، مع دعم تشغيل الصوت عبر DFPlayer، التحكم بواسطة MQTT، تحديثات OTA، وإدارة مواقيت الصلاة.

---

# 📌 نظرة عامة على المشروع

نظام ESP Prayer System هو جهاز إلكتروني ذكي مصمم من أجل:

- حساب وإدارة مواقيت الصلاة.
- تشغيل الأذان تلقائياً عند دخول وقت الصلاة.
- التحكم بالصوت باستخدام وحدة DFPlayer Mini.
- عرض معلومات الصلاة على شاشات LCD/OLED.
- دعم الاتصال بشبكة WiFi.
- التحكم عن بعد باستخدام MQTT.
- دعم تحديث البرنامج لاسلكياً OTA.
- حفظ الإعدادات محلياً.

تم تصميم النظام باستخدام هيكل برمجي معياري بواسطة PlatformIO لتسهيل التطوير والتوسعة.
